# Conditionals

Type 0 (general truth), Type 1 (real future: `if + present, will + base`), Type 2 (unreal present: `if + past, would + base`), Type 3 (unreal past).

Most common error: putting "will" in the if-clause ("If I will study" → "If I study"). This backshift rule is the core hurdle.

Often drilled together with [[relative-clauses]] for exam readiness.
