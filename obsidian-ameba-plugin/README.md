# 🧬 Amoeba System — Obsidian 플러그인

**진짜 Obsidian 위에서 동작하는 플러그인**입니다. 기존 Obsidian의 노트·그래프 위에
**아메바 시스템**을 얹어, 학생 노트가 **세대를 거쳐 스스로 융합(수렴)하고 분기(발산)하며
진화**하는 살아있는 그래프를 보여줍니다. 영어 1:1 강사를 위해 설계되었습니다.

> 융합/분기는 버튼으로 일으키는 게 아니라, **물리 시뮬레이션에서 자발적으로 emergent하게**
> 일어납니다. 비슷한 노드는 서로 끌려가 충돌하면 **융합**하고, 내부 이질성(긴장)이 쌓인
> 노드는 **분기**되어 갈라집니다.

---

## 📦 설치 (수동)

이 플러그인은 빌드 산출물(`main.js`)이 포함되어 있어 **빌드 없이 바로 설치**됩니다.

1. 내 볼트의 플러그인 폴더로 이 폴더 전체를 복사합니다:
   ```
   <내 볼트>/.obsidian/plugins/amoeba-system/
     ├── manifest.json
     ├── main.js
     └── styles.css
   ```
   (이 셋만 있으면 동작합니다. `src/`, `package.json` 등은 개발용)
2. Obsidian → 설정 → **커뮤니티 플러그인** → 새로고침 → **Amoeba System** 켜기
3. 좌측 리본의 **🍴(git-fork) 아이콘** 클릭, 또는 명령어 팔레트에서 `Amoeba System 열기`

> 처음 테스트할 볼트가 없다면, 같은 저장소의 `obsidian-ameba/vault/` 폴더를 Obsidian 볼트로
> 열면 학생 3명(Jiwon/Minseo/Daniel)의 예시 노트로 바로 진화를 볼 수 있습니다.

## 📝 노트 작성 규칙 (아메바의 먹이)

`student` frontmatter가 있는 노트만 해당 학생의 아메바로 들어갑니다.

```markdown
---
student: Jiwon Park
session: 3
date: 2026-05-12
category: grammar          # grammar|vocabulary|pronunciation|fluency|listening|
                           # writing|confidence|interests|goals|errors
tags: [present-perfect, articles]
strength: 0.7              # 0.0~1.0 관찰 확신도
---
지원은 압박 상황에서 관사를 자주 누락한다 ...
```

- **tags** 가 융합/분기의 핵심 신호입니다. 같은 결의 관찰엔 같은 태그를 재사용하세요.
- **category** 가 같으면 서로 잘 끌립니다.
- **strength** 가 높을수록 오래 살아남고(도태에 강함), 융합 시 가중치가 큽니다.

## 🧫 동작 원리 (알고리즘)

| 현상 | 트리거 | 방법 |
|------|--------|------|
| **유입** | 노트 1개 | 관찰 세포 1개로 시작 |
| **융합 (수렴)** | 유사도 높은 두 노드가 물리적으로 **충돌** | 태그/키워드 코사인 + 같은 카테고리 보너스 → 짧은 스프링으로 끌어당겨 충돌 시 자동 융합 |
| **분기 (발산)** | 융합 세포의 **내부 긴장**이 임계 초과 | 공통(일반) 태그를 제거하고 하위 구조를 2-means로 분리 → 두 전문 특질이 서로 밀어내며 갈라짐 (예: `pronunciation` → `th-sound` ⟂ `r-l`) |
| **도태** | 오래 보강 안 된 약한 단일 세포 | strength 감쇠 후 소멸 (큰 클러스터는 보강되어 생존) |
| **고도화 지수** | 구조 정제도 | 수렴률·카테고리 커버리지·평균 강도로 산출하는 "천재 지수" |

분기된 두 자식은 공통 태그가 제거되어 서로 유사도가 낮아지므로 **다시 합쳐지지 않고**,
각자 다른 노드와 자연스럽게 어울립니다. 그래서 융합과 분기가 **균형을 이루며 영원히
살아 움직입니다**.

## 🎛 화면

- **그래프(좌)**: Obsidian 그래프 스타일 — 노드(특질)·링크(유사도)·글로우, 드래그·줌·팬,
  노드 클릭 시 원본 노트 열기. 테마 색을 그대로 따릅니다.
- **사이드 패널(우)**: 고도화 지수, 다음 수업 추천, 실시간 진화 로그, 특질 목록.
- **툴바**: 학생 선택 · ⏯ 재생/정지 · 속도(0.5~4×) · 재배양 · 노트 다시읽기.

## 🛠 개발

```bash
npm install
npm run dev      # esbuild watch → main.js
npm run build    # tsc 타입체크 + 프로덕션 빌드
node tools/test-engine.mjs   # 엔진 융합/분기 헤드리스 검증
```

| 파일 | 역할 |
|------|------|
| `src/engine.ts` | 아메바 엔진 — 유사도/융합/분기/긴장/도태/점수/추천 (휴리스틱) |
| `src/view.ts` | 살아있는 포스 그래프 뷰 (옵시디언 비주얼, emergent 융합/분기) |
| `src/main.ts` | 플러그인 진입 — 볼트 스캔, 뷰/리본/커맨드/설정 |

알고리즘 튜닝은 `engine.ts` 의 `CFG`(mergeThreshold, tensionThreshold 등)에서 합니다.
